% =============================================================================
% NOTES: NaN values after reconciliation in M5 dataset
% =============================================================================
%
% Observation:
% - 30490 time series total in M5
% - Base forecasts: 0 NaN NRMSE values
% - After reconciliation (e.g. TH_5_9): 36 NaN values = 18 series x 2 granularities (Days + Months)
% - This is 0.06% of the dataset
%
% Root cause:
% The shrinkage covariance estimator (shr) becomes singular for certain time series.
% M5 contains many near-constant or zero-dominated series (low daily sales).
% When such a series has zero residual variance at one or more aggregation levels
% in the hierarchy, the sample covariance matrix used by the shrinkage estimator
% is rank-deficient or has zero diagonal entries. This causes:
%   1. Division by zero in the standardization step of shrink_estim (dividing by sqrt(diag))
%   2. Singular linear system in the projection step (jnp.linalg.solve fails)
% The reconciliation correctly signals it cannot operate — the "optimal" weighting
% is undefined when error covariance doesn't exist.
%
% Why this only happens after reconciliation, not for base forecasts:
% Base forecasts are computed independently per level — no cross-level covariance needed.
% Reconciliation requires estimating the joint covariance across all hierarchy levels.
% Larger hierarchies (more levels) = higher-dimensional covariance = more chances for degeneracy.
% The minimal hierarchy (Months+Days) has fewer dimensions and doesn't trigger this.
%
% Why fallback methods are not appropriate for a research paper:
% - Falling back to OLS for problematic series means applying a hybrid shr+ols method,
%   not a uniform method. This muddies the comparison and is hard to defend in review.
% - Adding noise or regularization fabricates information that doesn't exist.
% - Both introduce conditional branches that could subtly bias results.
%
% Defensible solution: drop the affected series
% - 18 out of 30490 series = 0.06%, negligible
% - These are degenerate cases where reconciliation is mathematically undefined
% - Standard practice in reconciliation literature
% - get_error_stats already computes over non-NaN values, so this is already happening implicitly
% - The count difference is visible: base has 30490, reconciled TH_5_9 has 30472
%
% What to verify:
% - Confirm 36 NaN = 18 series x 2 granularities (same series affected at both levels)
% - Statistical tests (Page's L, slope t-test) and conformism handle NaN consistently
% - Either intersect to common valid set across all hierarchies in a sequence,
%   or confirm the few dropouts don't vary meaningfully between hierarchy heights
%
% Paper wording suggestion:
% "X series (0.06%) were excluded per hierarchy where the shrinkage covariance
%  estimator was singular due to zero residual variance at one or more aggregation
%  levels — a known degeneracy with near-constant time series in the M5 dataset."
%
